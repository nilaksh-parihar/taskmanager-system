
# Task Management System

## Tech Stack

- FastAPI
- PostgreSQL
- React
- JWT Authentication

## Features

- User Registration
- User Login
- JWT Authentication
- Task CRUD
- Protected Routes
- PostgreSQL Integration

## Backend Setup

cd backend

python -m venv venv

pip install -r requirements.txt

python -m uvicorn app.main:app --reload

## Frontend Setup

cd frontend

npm install

npm run dev
# taskmanager-system
The application provides secure user authentication using JWT tokens, role-based access control, and complete task management functionality. Users can register, log in, create tasks, view their tasks, update task details, and delete tasks. The backend is built with FastAPI and PostgreSQL, while the frontend is developed using React and Material UI.
