# Task Management System

## Tech Stack

- FastAPI
- PostgreSQL
- React
- JWT Authentication

## Features

- User Registration
- User Login
- JWT Authentication
- Task CRUD
- Protected Routes
- PostgreSQL Integration

## Backend Setup

cd backend

python -m venv venv

pip install -r requirements.txt

python -m uvicorn app.main:app --reload

## Frontend Setup

cd frontend

npm install

npm run dev
